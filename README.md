# AI 다이어트 코치 (AI Diet Coach)

그날 먹은 **음식 사진**과 **운동 기록**을 입력하면, Google Gemini Vision AI가 칼로리와 영양 성분을 분석하고 기초대사량(BMR)/활동대사량(TDEE)을 고려하여 **다이어트 기여도 및 예상 감량치(체중 변화)**를 정밀 예측해 주는 웹 애플리케이션입니다.

---

## 🌟 주요 기능

1. **식단 사진 AI 영양 스캐너 (Gemini Vision)**:
   - 스마트폰 사진이나 이미지를 올리면 메뉴 식별, 칼로리(kcal), 탄수화물/단백질/지방/식이섬유 자동 추출.
   - 영양사 관점의 다이어트 피드백 코멘트 제공 및 사용자 직접 수정 기능.
   - 빠른 데모를 위한 샘플 식단 프리셋(닭가슴살 샐러드, 연어 스테이크, 소고기 덮밥 등) 지원.

2. **스마트 운동 기록기 (MET 기반 소모 칼로리 계산)**:
   - 러닝, 웨이트 트레이닝, 실내자전거, 수영, HIIT, 필라테스 등 추천 종목 프리셋.
   - 운동 시간 및 강도(가벼움/보통/격렬함)와 사용자 체중에 기반한 정확한 소모 칼로리 산출.

3. **칼로리 수지 분석 (Calorie Deficit / Surplus)**:
   - `순 칼로리 = 총 섭취 - (유지대사량 TDEE + 운동 소모량)`
   - 건강한 감량 황금 구간(300~900 kcal 적자), 극단적 절식 경고, 초과 섭취 상태 알림.
   - 단백질 권장 섭취량 달성률(%) 및 탄단지 밸런스 실시간 모니터링.

4. **다이어트 성과 & 감량 예측 엔진**:
   - 1주 예상 체중 변화 (kg)
   - 30일(한 달) 예상 체중 변화 (kg)
   - 목표 체중 도달 예상 D-Day 카운트다운
   - 오늘의 다이어트 점수 (0 ~ 100점 & 등급 S/A/B/C)
   - Gemini AI 맞춤 코칭 리포트 (총평, 칭찬할 점, 개선점, 내일 실천 미션)

5. **날짜별 기록 및 로컬 저장**:
   - 일자별 캘린더 네비게이션으로 과거 기록 조회.
   - 브라우저 LocalStorage 기반으로 새로고침해도 안전하게 보존.

## 🚀 시작하기

### 1. 개발 서버 실행
```bash
cd ai-diet-coach
npm run dev
```

브라우저에서 `http://localhost:3000` 접속

### 2. 빌드 및 프로덕션 실행
```bash
npm run build
npm run start
```

### 3. 환경 변수 (`.env.local`)
```env
GEMINI_API_KEY=your_gemini_api_key_here
```
(Google AI Studio에서 무료로 발급받을 수 있습니다)
